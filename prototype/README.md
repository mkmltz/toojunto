# TooJunto — Protótipo Funcional MVP 0.1

## Objetivo
Validar a compreensão da jornada principal antes do desenvolvimento do produto:
**Criar → Convidar → Entrar → Pagar → Registrar → Sortear → Acompanhar**

## Como executar
Não há build, servidor ou dependência externa.

1. Extraia este ZIP.
2. Abra `index.html` no navegador.
3. Use o botão `MS` no topo para alternar entre Gestor e Participante.
4. Os dados ficam no `localStorage` do navegador.
5. Para voltar ao cenário inicial, abra `?` e escolha **Resetar demonstração**.

## Fluxo de autenticação
- Tela de Login
- Criar conta
- Recuperação de senha (mensagem simulada)
- Sair da conta

## O que está simulado
- Criação de grupo
- Convites
- Geração de link único de convite
- Cópia do link para envio no WhatsApp
- Mensagem pronta para WhatsApp
- Abertura simulada do WhatsApp
- Aceite de convite
- Visualização do grupo
- Sorteio
- Resultado do sorteio
- Registro de pagamento
- Confirmação/recusa pelo gestor
- Contemplação
- Histórico

## Fora do protótipo
- Backend e banco de dados
- Autenticação real
- Pix real / movimentação financeira
- WhatsApp integrado
- Notificações automáticas
- Regras automáticas de inadimplência, multas e substitutos
- KYC/Open Finance
- App nativo
